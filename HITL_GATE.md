# Shadow Field v2 · Final HITL Gate

This gate occurs **after implementation draft and tests are available, but before the draft is declared complete or replaces the existing public Shadow Field**.

Human review is required on four questions only.

## 1. Philosophical landing

Does this proposition hold?

> Utility is a property of a state in relation to the immediate order, not the measure of whether that state deserves to exist.

And does **legitimate remainder** correctly capture states that are not useful now but still have a rational place outside the immediate order?

## 2. State vocabulary

Does the initial set adequately preserve the intended distinctions?

- being
- considering
- attempting
- trying
- hidden
- deferred
- infecting / transmitting
- conferring / enabling

The test is not whether the vocabulary is complete forever. The test is whether it distorts the current idea.

## 3. Authority boundary

Does the implemented hierarchy correctly allocate authority?

`source → observation → inference → relationship → representation → action`

Specifically: is the system analysing the user rather than authoring the user?

## 4. Public replacement decision

After the falsification tests pass, should `shadow.html` replace the missing/current Shadow Field public route?

### Decision states

- **ACCEPT** — publish as Shadow Field v2.
- **AMEND** — change the named layer only, then repeat relevant tests.
- **REJECT** — do not replace the existing conceptual architecture.

No additional approval loop is required before this gate.
